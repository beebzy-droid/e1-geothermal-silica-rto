# Manuscript LaTeX
Two ways to build:
1. **Local (MiKTeX/TeX Live installed):** run `compile.bat` from this folder.
   Needs the `elsarticle` class (MiKTeX auto-installs on first compile).
2. **Overleaf (recommended, zero install):** create a project and upload
   this folder, the repo `figures/` folder, and `literature/references.bib`
   (place it next to main.tex as `references.bib`; fix `\graphicspath` to
   `{figures/}` if you flatten the structure).
Prose status: sections are scaffolds with slotted numbers (build 3-4 fill
them). Rule: numbers are cited from committed CSVs, never retyped.
