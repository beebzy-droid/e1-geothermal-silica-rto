# Third-party inputs (not redistributed)

- **Scott et al. (2024) supplementary dataset** — download the Excel
  file from the article's Supplementary material
  (doi:10.1016/j.gca.2024.02.017) and save it as
  `literature/scott2024_supplementary_dataset.xlsx`. Three gate modules
  (`scott2024_dataset.py`, `kinetics_validation.py`,
  `sensor_validation_scott.py`) need it and fail without it.
- **Cited papers** are not included. See `literature/references.bib`.
- An author-provided reference script for the Scott et al. model was
  used for cross-checking only and is not part of this repository.

Everything else — transcribed primary tables under `src/data/`, all
code, and every file under `results/` — is original to this repository.
